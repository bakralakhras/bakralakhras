## Featured projects

**[Sovereign Data Lakehouse on OpenShift](https://github.com/bakralakhras/OpenShift-ArgoCD)**
An 8-node OpenShift 4.21 platform run entirely through Argo CD (27 applications): Kafka KRaft, Spark Structured Streaming, Iceberg on MinIO, Hive Metastore, Trino, Airflow, Vault, Prometheus, Thanos and Grafana, plus a React and FastAPI operations console I built. A real-time fraud pipeline on the IEEE-CIS dataset processed 994,376 transaction decisions end to end.

**[Aegis: MLOps platform on Nutanix NKP](https://github.com/bakralakhras/MLOPS_NKP)**
The full ML lifecycle on Kubernetes in eight phases: distributed MinIO, Airflow-orchestrated feature and training pipelines, MLflow tracking and registry, KServe and MLServer inference, Flux GitOps, Vault, default-deny network policies and Metoro observability. Validated end to end with live fraud inference.

**[IncidentVault](https://github.com/bakralakhras/IncidentVault)**
A FastAPI incident service with SQLAlchemy, Alembic migrations, a Pytest suite, GitHub Actions CI, Docker and Helm.
